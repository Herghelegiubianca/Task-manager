Task Management System

A Java-based desktop application designed for project managers to efficiently handle employees, 
assign tasks, track work durations, and generate statistics. The project strictly follows the MVC 
(Model-View-Controller) architecture and a layered package structure, ensuring clean code separation 
and maintainability.

Features:

Employee Management: Add employees, filter them based on specific criteria, and view employee statistics.

Advanced Task Handling: Create and manage both Simple Tasks and Complex Tasks (tasks containing sub-tasks), demonstrating robust polymorphic behavior.

Task Assignment & Tracking: Assign tasks to specific employees, modify task statuses, and automatically calculate total estimated work durations.

Data Persistence: Save and load system states locally using serialization operations.

Interactive GUI: Fully functional Graphical User Interface with dedicated controllers for distinct operational flows.
